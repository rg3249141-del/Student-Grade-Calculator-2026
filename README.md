# Student-Grade-Calculator-2026

A python based student grade calculator that calculates total marks, percentage, grade and pass/fail result.

## Features

- Accepts student name and marks in five subjects.
- Calculates total marks and percentage.
- Assigns grades based on percentage.
- Displays pass or fail status.
- Validates marks between 0 and 100.
- Supports multiple students.
  
  ## Technologies Used

- Python 3
- Visual Studio Code (VS Code)
- GitHub
  
  ## How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   python student_grade_calculator.py

6. Enter the student name and marks when prompted.

  ## Test Cases

1. Normal input – Student passes with Grade B.
2. Low marks – Student fails with Grade F.
3. Invalid marks – Rejects marks above 100.
4. Multiple students – Calculates results for different students.
5. Boundary value – Exactly 40% gives Grade D and Pass.
6. Alphabet input – Rejects non-numeric marks.
